# Source data

The source CSV files are intentionally not included in this public repository because the hackathon brief identifies the dataset as educational/hackathon-use material and advises against public redistribution.

To run the scripts, obtain the authorised dataset from the hackathon organisers/source and place these files in this folder:

- `Customer Loyalty History.csv`
- `Customer Flight Activity.csv`
- `Calendar.csv`

The scripts expect these filenames. Do not commit source CSVs, member-level exports, or other data files unless you have explicit permission to redistribute them.
